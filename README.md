MetroPT-3 Predictive Maintenance & Equipment Intelligence

Project Overview

This project analyses real operational sensor data from a metro train air compressor to investigate equipment behaviour, pressure and temperature trends, motor-current patterns, and documented air-leak events.

Business Objectives

* Analyse compressor sensor readings and operating conditions.
* Investigate sensor patterns around documented air-leak events.
* Identify unusual operating conditions that may require further investigation.
* Develop a dashboard to communicate maintenance insights.

Technology Stack

* Python
* Pandas and NumPy
* Matplotlib and Seaborn
* SciPy
* Jupyter Notebook
* Tableau
* Git and GitHub

Dataset

Source: UCI Machine Learning Repository — MetroPT-3

The dataset contains real operational measurements from a metro train compressor. The raw dataset is stored locally and is not included in this repository.

Project Workflow

1. Data inspection and quality assessment
2. Sensor and operating-state analysis
3. Pressure and temperature trend analysis
4. Investigation of documented air-leak events
5. Anomaly detection and evaluation
6. Tableau dashboard development
7. Business insights and maintenance reporting

Limitations

An unusual sensor reading does not automatically indicate equipment failure. Findings will be evaluated against the available documentation and event information.

This project uses metro compressor data. The analytical methods may be relevant to industrial maintenance, but equipment-specific conclusions cannot automatically be transferred to other machines.
